# 홈핏 메이트 (HomeFit Mate)

신체 정보와 난이도에 맞춘 맨몸운동 추천 웹 · 공학컴퓨터프로그래밍 기말 프로젝트

**조: 간장고장고장장** — 고의찬, 강군호, 장선민

## 실행 방법 (윈도우)

**처음 한 번만:** [python.org](https://www.python.org/downloads/)에서 Python을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.

| 방법 | 하는 법 |
|---|---|
| 바로 실행 | `홈핏메이트_실행.bat` 더블클릭 → 앱 창이 열림 |
| exe 만들기 | `exe_만들기.bat` 더블클릭 → `dist\HomeFitMate.exe` 생성. 이 파일 하나만 있으면 Python 없는 컴퓨터에서도 실행됨 |

- 앱 창은 Edge(또는 Chrome)의 주소창 없는 앱 모드로 열립니다.
- 같이 뜨는 검은 창을 닫으면 프로그램이 종료됩니다.
- 운동 기록은 프로그램 옆 `data` 폴더에 저장됩니다.
- 윈도우가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누르세요. 직접 만든 exe라 서명이 없어서 나오는 경고입니다.

### 개발할 때

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속

## 화면 흐름

```
(처음 실행) 정보 입력 → 홈 → 루틴 추천 → 운동 진행 → 완료 → 홈
```

| 주소 | 화면 |
|---|---|
| `/` | 홈 — 마스코트, 연속 운동 일수 |
| `/profile` | 키·몸무게·난이도 입력 (`data/user.json`에 저장) |
| `/routine?part=하체` | 오늘의 루틴 (부위: 전신/상체/하체/코어) |
| `/workout/<번호>` | 운동 진행 — 시범 영상, 횟수·세트, 설명 |
| `/done` | 완료 — 기록 저장, 소모 칼로리 |
| `/history` | 운동 기록 — 월별 달력, 통계, 배지 6종, 최근 운동 |
| `/exercises` | 운동 도감 — 전체 운동 목록, 부위 필터 |
| `/exercises/<이름>` | 운동 상세 — 시범 영상, 난이도, 관절 부담, 동작 설명 |
| `/stages` | 발표용 — 쉬면 변하는 화면 4단계 한눈에 비교 |

화면 아래 탭(홈 / 운동 도감 / 기록 / 내 정보)으로 이동할 수 있고, 내 정보 화면에서는 BMI도 보여줍니다.

## 운동 공백에 따라 변하는 화면

| 마지막 운동 후 | 화면 |
|---|---|
| 0~2일 | 웃는 마스코트, 기본 색 |
| 3~6일 | 시무룩한 마스코트, 색이 흐려짐 |
| 7~13일 | 화난 마스코트, 상단 경고 배너 |
| 14일 이상 | 쓰러진 마스코트, 화면 전체 흑백 |

**발표 시연용:** 주소 뒤에 `?days=숫자`를 붙이면 그 일수로 미리 볼 수 있습니다.
예) `http://127.0.0.1:5000/?days=20` → 흑백 화면

## 폴더 구조

```
app.py                 Flask 라우팅, 화면 전환            (장선민)
launcher.py            윈도우 앱 창으로 실행              (장선민)
services/stage.py      공백 일수 → 화면 단계 결정          (장선민)
services/storage.py    JSON 저장·불러오기, 공백·연속 일수   (강군호, 현재 임시 구현)
services/routine.py    루틴 추천, 칼로리 계산              (강군호, 현재 임시 구현)
data/exercises.json    운동 데이터                        (고의찬, 현재 샘플 10개)
templates/             화면 HTML                          (장선민)
static/css/style.css   스타일, 단계별 테마                 (장선민)
static/mascot/         마스코트 핏이 표정 4종              (장선민)
static/videos/         시범 영상                          (고의찬)
```

## 팀원에게

- **강군호:** `storage.py`, `routine.py`는 화면이 돌아가게 하려고 넣은 임시 코드입니다. 함수 이름과 반환 형태만 유지하면 내부 로직은 자유롭게 바꿔도 화면은 그대로 동작합니다. `recommend()`는 운동 딕셔너리 리스트, `days_since_last_workout()`는 정수(기록 없으면 `None`)를 반환하면 됩니다.
- **고의찬:** `data/exercises.json`에 운동을 추가하면 바로 반영됩니다. 영상은 `static/videos/`에 넣고 `video` 항목에 경로를 적으면 운동 화면에 재생됩니다. 영상이 없으면 "시범 영상 준비 중"으로 표시됩니다. 관리자 업로드 화면과 타이머는 아직 없습니다.
