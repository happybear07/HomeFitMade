홈핏 메이트 화면 설계

흐름: 정보 입력 → 홈 → 루틴 추천 → 운동 진행 → 휴식 → 완료. 화면 ID(S1~S7)와 기능 ID(A-1, C-3 등)는 기능명세서 v0.1과 같습니다.
제목을 누르면 화면이 실제 크기로 열리고, 화면 속 버튼으로 다른 화면으로 이동할 수 있습니다. 숫자는 예시 데이터입니다. 색은 팔레트 03 민트 클레이입니다.

디자인 시스템 v0.6

S1 정보 입력

S1 정보 입력 (홈의 설정 버튼으로도 열림)
A-1 입력 · A-2 검증(몸무게 칸은 오류 상태 예시) · A-3 BMI와 한국 기준 막대 · A-5 다시 열어 수정 · A-6 BMI 참고 안내 · SR-2 건강 안내
난이도 설명은 ACSM 2009의 초보·중급·고급 정의를 따름

S2 홈 · G0 기본 (0~2일)

S2 홈 G0 (마지막 운동 후 0~2일)
틸 헤더의 이번 주 줄: 검정 = 완료, 점선 = 중단, 흰색 = 오늘 · E-2 연속 일수 · F-1~F-3 공백 단계
가운데 재생 버튼 = 오늘의 루틴 시작 · state 속성으로 G0~G3 전환

S3 루틴 추천

S3 루틴 추천
C-1~C-5 추천 결과와 예상 시간 · C-7 부위 선택(알약형) · C-3 관절 부담 표시(BMI 25 이상이면 대체 운동으로 바뀜) · H-1, H-3 자동 조정 안내
왼쪽 썸네일은 시범 영상 자리

S4 운동 진행

S4 운동 진행 (어두운 영상 영역 + 흰 시트)
D-1 시범 영상 · D-2 영상이 없으면 '영상 준비 중'과 설명만 표시 · D-3 세트·횟수 · D-4 X 버튼 = 그만하기, 건너뛰기 · SR-4 주의사항

S4 운동 진행 · 휴식

S4 휴식 (틸 영역 + 흰 시트)
D-5 휴식 타이머 · 시간형 운동(플랭크 등)은 운동 타이머가 끝나면 자동으로 이 화면으로 넘어옴

S5 완료

S5 완료
E-1 기록 저장 · E-2 연속 일수 · E-4 칼로리(MET 기반, 휴식 제외 추정) · F-4 홈이 기본 상태로 돌아옴
'오늘 운동은 어땠나요?' 3단계는 기능명세서 I-3(선택) 시안

S2 홈 · G1 시무룩 (3~6일)

G1 시무룩 (3~6일)
Main을 state=g1로 불러옴 · F-3 화면 채도 낮춤 (CSS filter: saturate)

S2 홈 · G2 화남 (7~13일)

G2 화남 (7~13일)
Main을 state=g2로 불러옴 · F-3 상단 경고 배너

S2 홈 · G3 쓰러짐 (14일 이상)

G3 쓰러짐 (14일 이상)
Main을 state=g3로 불러옴 · F-3 화면 전체 흑백 (CSS filter: grayscale) · F-4 루틴을 끝내면 G0로 복귀

S6 운동 기록

S6 운동 기록
E-5 달력과 목록 · 완료·중단 구분
'부위별 운동량' 도넛은 레퍼런스에서 가져온 제안이라 명세서에는 없음(빼도 됨)

S7 관리자 · 시범 영상

S7 관리자 (S1 오른쪽 위 '관리자'에서 진입)
G-1 등록 현황 · G-2 업로드 · G-3 형식·용량 오류(오류 상태 예시)

곰 마스코트 컴포넌트 (mood 속성)

하단 탭 컴포넌트 (active 속성)
